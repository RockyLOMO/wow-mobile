# WoW Mobile / Winlator：改成“手游式直接点击技能”触控布局

## S10 当前已配置（2026-10-02）

手机 **WoW Mobile v0.1.2** 已导入 [S10 实际触控配置](WoW-Mobile-S10-Touch-Skills.icp)。从 WoW Mobile 首页点 **Play** 后，已看到新布局自动加载：左侧 WASD 方向键，右侧两行 `1`～`6`，底部有跳跃、选怪、`F互动`、鼠标左/右键，顶部有菜单、背包、镜头和地图。原布局已另存为 [备份](WoW-Mobile-S10-Original-ConsolePortLK.icp)，手机里也保留 `WoW ConsolePortLK Backup`。

配置对应的按键：技能 `1`～`6`、选怪 `TAB`、跳跃 `SPACE`、互动 `F`、背包 `B`、地图 `M`、菜单 `ESC`。WoW Mobile 已在该账号的 `bindings-cache.wtf` 写入 `bind F INTERACTTARGET`。2026-10-02 手机成功进入 `Firstkiller` 的游戏世界，服务端数据库显示角色在线；方向键按住后场景移动，按技能 `1` 后游戏出现“没有目标”提示，证明这两个输入已传到客户端。其他数字键、选怪、互动/拾取、镜头拖动仍未逐项实战验收。

首次进入世界时 ConsolePort 弹出加载默认手柄按键的窗口，并在屏幕下方叠加手柄动作栏。已针对手机上的 `Firstkiller` 禁用 `ConsolePort`、`ConsolePortUI`、`ConsolePortUI_NPC` 并重新载入界面；`WTF/Account/WOWADMIN/AzerothCore/Firstkiller/AddOns.txt` 记录为 `disabled`，原生数字动作栏现已显示。其他角色首次进入时可能也需要关闭这三个插件。插件文件仍在手机上；此变更只针对手机客户端，不改 PC 客户端。手机客户端通过域名 `cloud.f-li.cn` 登录，本次连接日志显示认证连接到公网解析地址 `58.209.44.49:3724`、世界服 `COP_AUTHENTICATE AUTH_OK`、`COP_LOGIN_CHARACTER result=TRUE`。手机仍连家中 Wi-Fi，并启用 NekoBox VPN，这次验证不能算独立蜂窝公网测试。

使用和恢复：

1. 平常直接从 WoW Mobile 首页点 **Play**，不必每次手动选触控配置。
2. 要改按钮：WoW Mobile 首页下滑 → **Advanced (Winlator UI)** → 菜单 **Input Controls** → 选 `WoW ConsolePortLK` → **Controls Editor**。不要改名，否则 Play 会找不到它。
3. 要恢复旧的手柄式布局：先将当前 `WoW ConsolePortLK` 改名为其他名字，再将 `WoW ConsolePortLK Backup` 改名为 `WoW ConsolePortLK`；或者从上面的备份 `.icp` 导入。保留两份配置，避免同名冲突。
4. 若需在其他手机导入本布局，把 `.icp` 放入手机 `Download`，在 **Input Controls → Import Profile → Open File** 选择它。导入前先备份并改名默认的 `WoW ConsolePortLK`；此应用的 Play 路径按这个固定名称自动选择配置。
5. 首次用新角色进入世界时，如果出现 ConsolePort 的默认按键弹窗，可在游戏内聊天框输入 `/run DisableAddOn("ConsolePort");ReloadUI()`；这会在当前角色关闭 ConsolePort 及依赖界面，并保留插件文件。若要恢复手柄界面，可在角色选择页的“插件”中重新启用 `ConsolePort` 及相关界面插件。

目前手机 `/sdcard/Download/WoW-Mobile-S10-Touch-Skills.icp` 也存有导入文件。全局 Overlay Opacity 为 40%，各按钮还有单独透明度；在游戏画面上看不清时，到 Input Controls 把全局透明度调高。技能键目前是可读数字按钮，**尚未与游戏动作栏图标精准重叠**；下面关于透明按钮覆盖图标的章节是后续优化方案，不代表已部署。

> 目标：把 WoW Mobile 默认的“Xbox 手柄式控制”改成更接近《王者荣耀》这种手游逻辑。  
> 适用：WoW 3.3.5a / AzerothCore / WoW Mobile / Winlator。  
> 建议设备：Android 横屏，三星 S10 也适用。

---

## 1. 最终想要的控制方式

不要再主要依赖：

- A / B / X / Y
- LB / LT / RB / RT
- L1 / L2 / R1 / R2
- Shift / Ctrl 组合键

改成：

- 左下角：虚拟摇杆移动
- 右下角：6～10 个技能按钮
- 点哪个技能按钮，就直接释放对应技能
- 右侧留少量功能键：选目标、互动/拾取、跳跃、宠物攻击、宠物跟随、地图/背包
- 屏幕右侧空白区域用于滑动镜头

## 2. 推荐横屏布局

```text
┌──────────────────────────────────────┐
│                                      │
│                               [地图] │
│                                      │
│                        [7] [8] [9]   │
│                                      │
│                    [4] [5] [6]      │
│                                      │
│    ◯ 移动           [1] [2] [3]     │
│                                      │
│  [选怪]       [跳] [拾取] [宠物]    │
└──────────────────────────────────────┘
```

推荐原则：

- 左手只负责移动
- 右手负责技能和功能键
- 常用技能放最右下、最好点的位置
- 不常用技能往上放
- 第一次建议只放 6 个技能按钮 + 4 个功能按钮

## 4. Winlator / WoW Mobile 触控按钮映射

在 Input Controls / Controls Editor 中创建或导入 Profile。WoW Mobile v0.1.2 的 Play 会固定选取名称为 `WoW ConsolePortLK` 的 Profile，因此若要自动加载，最终使用的配置必须是这个名字。

建议新建：

```text
WoW ConsolePortLK
```

先导出原来的默认手柄式 Profile，并把它改名为 `WoW ConsolePortLK Backup`，再导入同名的新布局，避免旧配置丢失。

然后依次添加按钮：

```text
技能按钮1 → KEY_1
技能按钮2 → KEY_2
技能按钮3 → KEY_3
技能按钮4 → KEY_4
技能按钮5 → KEY_5
技能按钮6 → KEY_6
技能按钮7 → KEY_7
技能按钮8 → KEY_8
技能按钮9 → KEY_9
技能按钮10 → KEY_0
```

如果需要更多：

```text
技能按钮11 → KEY_F1
技能按钮12 → KEY_F2
技能按钮13 → KEY_F3
技能按钮14 → KEY_F4
```

## 5. 让按钮看起来像真正技能图标

推荐把 WoW 原生动作栏移到屏幕右下，并排成：

```text
[1][2][3]
[4][5][6]
[7][8][9]
```

然后在 Winlator 中创建相同位置的透明按钮，正好盖在对应技能图标上。

透明度建议：

```text
Opacity / Alpha：10% ～ 30%
```

这样能直接看到：

- WoW 原生技能图标
- CD 倒计时
- 技能变灰
- 可用/不可用状态
- 资源不足状态

但触摸时实际上是：

```text
点透明按钮
→ Winlator 发送 KEY_1
→ WoW 释放动作栏技能1
```

这最接近真正手游。

## 7. 选择目标

创建独立按钮：

```text
[选怪]
```

映射：

```text
TAB
```

作用：

```text
点一下 → 选择最近敌人
再点 → 切到下一敌人
```

推荐放在左下摇杆右侧，或者技能区边缘。

## 8. 拾取 / NPC互动

创建独立按钮：

```text
[互动]
```

或：

```text
[拾取]
```

优先绑定 WoW 的 Interact With Target / INTERACTTARGET，或者 INTERACTMOUSEOVER 对应快捷键。

用途：

- 尸体拾取
- 与 NPC 对话
- 商人
- 接任务 / 交任务
- 可互动物体

同时建议在 WoW 里开启：

```text
Auto Loot / 自动拾取
```

这样：

```text
怪死 → 靠近 → 点“拾取” → 物品自动进包
```

## 10. 镜头控制

## 15. ConsolePort 怎么处理

改成这种“直接点击技能”玩法后：

**ConsolePort 不再作为主要技能控制方式。**

当前 S10 的 `Firstkiller` 已禁用 ConsolePort，但保留了插件文件和原布局备份。使用这套数字技能布局时，不再依赖：

```text
LB + A
LT + B
RB + X
Shift / Ctrl 多层技能
```

技能尽量全部改成单键数字映射。

如果出现“点一次按钮却触发两个技能”，优先检查：

- ConsolePort 是否也绑定了同一个键
- WoWpadX 是否又做了一层映射
- Steam Input
- DS4Windows
- reWASD
- JoyToKey
- 其他手柄映射工具

原则：

**一个触摸输入只保留一套映射。**

- [ ] 猎人宠物可以跟随

- [x] 关闭该角色 ConsolePort 后，WoW 原生动作栏显示

## 20. 最终目标体验

最终不是：

```text
Xbox 手柄模拟器
```

而是：

```text
左手摇杆移动
+
右手直接点技能
+
一键选怪
+
一键拾取
+
滑屏转镜头
```

也就是尽量接近《王者荣耀》或普通手机 MMO 的操作逻辑。

对于 WoW 3.3.5a、休闲任务、猎人练级，这种控制方式通常会比 ConsolePort 的多层组合键更直观。
