# 旧梦WOW：安装与使用手册

整理日期：2026-10-08；当前功能为2026-10-08的v13阶段版本，APK包版本为0.1.2。10月8日已验证S10键盘入口和原生动作栏恢复；下载验收仍沿用10月7日记录。这里的“自动”指全新安装且没有恢复旧App数据，允许读取完整客户端后，由App准备客户端、登录游戏时生效；APK不会把S10上的人物和个人配置打包复制给另一台手机。

## 首次安装与客户端下载

1. [下载APK](https://cloud.f-li.cn:6500/wow/OldDreamWOW.apk)，在个人/Main Profile安装；系统提示时允许安装和存储访问。
2. 首次提示后台运行权限时点“一键设置”，在系统授权框确认允许。三星等机型若仍限制后台，再从休眠/深度休眠名单移出旧梦WOW。
3. 打开App。已有完整客户端会自动进入游戏启动流程；未找到时选择现有目录或点击下载。全新下载安装建议至少45 GB可用空间。
4. 下载、校验、解压均有进度，可通过App或通知暂停。下载继续会复用正确分片和片内断点；暂停解压后继续会重新解压暂存内容。无需手工合并六片。
5. 完成后自动运行，登录自己的账号并选择角色。右侧栏未显示时按下文开启，技能按自己的职业安排。

默认客户端目录为`/sdcard/Download/OldDream/client`；手动复制可使用`/sdcard/WoW335CN`，或在App选择同时包含`Wow.exe`和`Data`的完整客户端根目录。APK不包含客户端，也不包含账号密码。不要直接在压缩包里运行或选择只有分片的目录。

**容量提示：**低于20 GB会提示，但20 GB并不够完成一次全新安装；下载缓存与解压文件同时占用空间，服务还会核对实际需求。下载失败时先按错误提示处理，再继续；不要自行删除缓存以免丢失断点。

## 游戏启动与触控

Play后出现旧梦宣传加载页，提示“预计30–120秒”。`mm:ss`是本次真实计时；百分比参考本机上一次成功耗时，首次以60秒为基准，并非游戏内部真实加载进度。检测到游戏画面后显示100%并收起；严格超过120秒才出现查看游戏画面按钮，手动查看不会改写历史成功耗时。

| 操作 | 效果 |
| --- | --- |
| 顶部中间键盘图标 | 显示/收起软键盘；输入前先点游戏里的输入框，聊天可按回车打开 |
| 左侧方向按钮 | 前后移动、左右横移 |
| 中文目标 / 跳跃 | 选择最近敌人 / 跳跃 |
| 轻点 | 左键点击技能、菜单或单位 |
| 快速拖动 | 转动镜头 |
| 长按后松手 | 右键交互；默认长按380ms |
| 长按后拖动 | 左键拖动物品或技能；此手势完整实机验收尚待补充 |
| 双指竖滑 | 滚轮；完整多指组合尚待实机验收 |

长按时长、镜头灵敏度可在App游戏设置调整。分辨率自动采用720高度及屏幕比例，S10为1520×720；通常无需手动降低分辨率。空地误触会保留目标，主动选择其他单位及Esc取消目标仍生效。

## 换设备时重点确认

- **右侧技能图标的放大、两列六行排列会自动带上。** 每条右栏12格排成两列六行，两条合计四列，缩放1.30。无需另装我们的Lua插件或导入触控配置。
- **点到场景空白不丢失目标会自动带上。** 默认原生触控模式登录时启用游戏“锁定目标”，无需再去界面设置勾选；主动选择其他单位和Esc取消目标仍正常。
- **右侧两条动作栏的开关并未由APK强制开启。** 如果新角色没有显示，仍要去游戏“界面 → 动作条”开启右边动作条、右边动作条2（两条右侧栏）。具体每格放什么技能，也需按角色调整。

## 一、APK自动提供的功能

| 项目 | 新设备自动行为 | 生效条件/说明 |
| --- | --- | --- |
| 名称、图标、宣传加载页 | 旧梦WOW名称/图标，Play后的旧梦宣传图，底部mm:ss计时和百分比进度条 | 按本机上一次成功启动耗时平滑推进，画面出现时100%并收起；提示预计30–120秒，超过120秒可手动查看画面 |
| 原生触控模式 | 新安装默认启用；启动前把旧ConsolePort目录移到客户端根目录`.olddream-consoleport` | 从旧数据恢复或升级时保留原来的模式选择；Legacy模式恢复目录并启用核心手柄插件，不启用Native专用优化 |
| 触屏方向、目标、跳跃 | 自动建立原生配置，中文目标/跳跃，左右为人物横移 | 不需额外导入icp或keybinds.json |
| 游戏按键 | W/S前后、A/D横移、Space跳跃、Tab选最近敌人 | Native登录时设置并保存 |
| 触控手势默认值 | 长按380ms、镜头灵敏度1.0 | 可在App游戏设置按个人习惯调整 |
| 渲染分辨率 | 高720，按实际屏幕比例计算偶数宽度；16:9=1280×720、19:9=1520×720、20:9=1600×720 | 游戏与容器分辨率同步，无需照抄S10分辨率 |
| 右侧技能栏外观 | 已显示的每条右栏自动排成两列六行，图标缩放1.30 | 保留技能槽内容与原有显隐规则；不负责强制开启两条栏 |
| 右侧技能命中区 | 图标周围每边扩展3个UI单位，覆盖格间小空隙 | 图标视觉大小不变，Native插件布局时生效 |
| 点空地保留目标 | Native登录时写入`deselectOnClick=0` | 需要内置WoWMobileTouchUI插件正常加载；不需要手动再设置 |
| 文字与底栏 | 按既有规则放大常用字体、聊天字和底栏，并限制底栏宽度 | 不改UIParent全局缩放，避免背包/窗口裁切 |
| 窗口模式 | 游戏使用最大化窗口，匹配容器视口 | 自动设置，减少旧客户端独占全屏丢失输入焦点的问题 |
| 自动客户端检测 | 检测已选目录、默认下载目录、`/sdcard/WoW335CN` | 客户端完整且存储权限已允许时，冷启动自动运行 |
| 下载与解压 | 自动下载六个.zip.001～.006分片，累计进度/速度、暂停继续、片内断点、逐片SHA-256及解压CRC校验，完成后自动进入游戏 | 用户只需点击下载，不需手动下载/合并；顺序写入同一ZIP缓存，保留旧单ZIP续传兼容；完整客户端并不包含在APK内 |
| 容量检查 | 下载前低于20 GB弹窗，服务继续检查实际下载/解压需求 | 全新下载建议45 GB可用空间；20 GB并非足够安装的承诺 |
| 后台授权入口 | 首次提示，一键打开系统后台授权框 | 入口自动带上，授权本身必须在每台手机确认 |
| 容器和游戏快捷方式 | 自动创建/复用WoW运行容器及客户端盘符 | 正常不需手动创建Wine容器 |
| 新初始化服务器 | 默认`cloud.f-li.cn` | App内游戏设置可改；保留已记录的用户服务器选择 |

## 二、首次安装必须做、或可能需要确认的设置

| 项目 | 是否需要手动 | 操作 |
| --- | --- | --- |
| 安装APK | 是 | 如系统要求，允许当前浏览器/文件管理器安装APK；装在个人/Main Profile，避免Work Profile再装一份 |
| 存储权限 | 是，每台设备授权 | 首次允许读取/写入客户端；拒绝后App无法读取完整客户端 |
| 后台运行权限 | 是，每台设备授权 | 首次提示点“一键设置”，系统框点“允许”；已允许后显示“后台运行已允许” |
| 厂商休眠列表 | 按系统情况 | 三星等机型如仍限制后台，把旧梦WOW移出休眠/深度休眠应用；此厂商名单不由APK跨设备复制 |
| 安装进度通知 | 系统如提示则允许 | 便于熄屏或切后台时看到下载、解压进度及暂停入口 |
| 完整客户端 | 是，二选一 | 点击下载自动解压；或手动复制后选择含Wow.exe与Data的完整根目录 |
| 账号密码、角色选择 | 是 | 登录自己的游戏账号；APK没有内置S10账号密码 |
| 两条右侧动作栏开关 | 未显示时需要 | 游戏“界面 → 动作条”，勾选右边动作条、右边动作条2；已有角色设置可能已显示 |
| 右侧每格技能、物品、宏 | 按角色需要 | 游戏中把常用技能放进右侧栏；APK提供外观和点击优化，不复制S10猎人的技能清单 |
| 锁定动作条 | 建议确认 | 游戏“界面 → 动作条 → 锁定动作条”，减少手指滑动把技能拖走；当前APK不强制改此开关 |
| 自动拾取 | 新初始化默认提供，已有账号仍需检查 | 初次客户端配置写入`autoLootDefault=1`；已存在的账号/客户端设置或初始化标记可能覆盖/保留旧值。若仍出现逐项拾取，游戏“界面 → 控制”确认自动拾取 |
| 自动修理、卖灰色物品 | 需要确认BigFoot账号选项 | 启用BigFoot/RepairHelper，再在大脚设置开启自动修理、自动出售灰色物品；只在相应商人处执行 |
| 商人/银行时自动开包、快速拾取 | 需要确认BigFoot账号选项 | 大脚设置中按需开启；APK没有重复写入这些账号SavedVariables |
| 其他机型按钮位置、图形驱动 | 有异常时再调 | 分辨率与放大规则自动复用；“目标/跳跃距技能栏约2px”只在S10验证，其他比例可能需微调触控位置。启动/渲染异常时检查容器图形驱动 |

**BigFoot与APK的边界：**当前下载客户端ZIP包含BigFoot插件文件，但检查到其中没有BigFoot/RepairHelper/SellerHelper的账号SavedVariables配置。S10以前开启的自动修理、卖灰色物品、自动开包不能据此视为其他设备已开启。手动复制完整客户端且包含相应账号WTF时，可能沿用旧设置，进入游戏后确认即可。

## 三、这些个人数据不随APK自动转移

| 数据 | 所在范围 | 换设备处理 |
| --- | --- | --- |
| 人物、等级、任务、物品等 | 游戏账号/服务器 | 登录原账号与角色；不是安装APK复制人物 |
| 技能槽内容、宏、角色界面选项 | 游戏账号/角色及客户端自己的保存文件 | 同角色以游戏实际保存结果为准；不同角色自行安排 |
| BigFoot自动修理等账号设置 | 客户端`WTF/Account/.../SavedVariables` | 手动配置，或迁移对应WTF后核对 |
| 自定义触控位置、长按时长、镜头灵敏度 | 旧手机App内部数据 | 新安装用默认值；APK本身不导出个人触控配置，系统恢复旧App数据时可能恢复旧选择 |
| 自己修改的Lua/其他插件 | 客户端`Interface/AddOns` | 按需复制；App只升级精确匹配的已知原始旧版，不覆盖玩家自行改过的触控Lua |
| 已下载客户端和断点缓存 | 手机存储 | APK不携带约20 GB客户端或旧手机的下载进度 |
| 上次成功启动耗时 | 手机App内部`olddream_startup`配置 | 新设备首次按60秒基准推进；成功显示游戏画面后记录本机耗时，手动查看或取消启动不覆盖成功记录 |
| Android权限、后台白名单 | 各设备/用户的系统设置 | 新手机重新授权；不要假设S10授权随APK继承 |
